# Interest Rate Management

This version adds an Admin/Staff Interest Rate Management page.

Open it from Admin Dashboard -> Interest Rates, or directly at:
http://localhost:3000/interest_rate_management/code.html

Available operations:
- View existing rates
- Search rates
- Add a rate
- Edit a rate
- Delete a rate (PostgreSQL foreign keys may prevent deleting rates already referenced by loans/fixed deposits)

New RateIDs are generated by the server as MAX(RateID)+1 because the current INTEREST_RATE table uses an integer primary key without an identity/sequence.
